## Featured Projects

### CHIP-8 Emulator
**C++ | Emulator Development**

A CHIP-8 emulator developed in C++, exploring low-level programming and the architecture of virtual machines.

- Implemented CPU instruction decoding and execution.
- Developed memory and register management.
- Implemented timers and input handling.
- Developed graphics rendering and display functionality.
- Explored bitwise operations and the fetch-decode-execute cycle.

[View Repository](https://github.com/wantonsoup)

### DirectX 11 Real-Time Rendering Engine
**C++ | DirectX 11 | Graphics Programming**

A real-time rendering engine developed using C++ and DirectX 11.

- Implemented Physically Based Rendering (PBR).
- Developed GPU instancing.
- Implemented frustum culling.
- Integrated OBJ model loading using TinyObjLoader.
- Developed basic post-processing effects.
- Implemented an FPS counter and investigated rendering issues.

[View Repository](https://github.com/wantonsoup)

A dynamic weather system being developed using C++ and Unreal Engine 5.

- Developing a centralised Weather Manager.
- Implementing configurable weather states.

- Managing atmospheric parameters, fog, lighting and weather effects.
